LOCKED BUSINESS RULES:

Packages:
- Builder = BDT 11,000 = 1 ID
- Turbo = BDT 44,000 = 4 IDs
- Super Turbo = BDT 143,000 = 13 IDs
- Hyper Turbo = BDT 242,000 = 22 IDs

Sponsor logic:
- External sponsor connects to the buyer’s first ID only.
- Additional IDs created by a multi-ID package belong to the buyer’s internal package structure.

Turbo example:
- External sponsor earns from the buyer’s first ID only.
- Standard ID value = BDT 11,000.
- Level-1 rate = 8%.
- External sponsor commission = BDT 880.
- Buyer’s first ID sponsors the remaining 3 package IDs.
- Those 3 IDs complete Level 1 for the buyer’s first ID.
- Level-1 total = 880 × 3 = BDT 2,640.
- After Level 1 is complete, BDT 2,640 is released to the wallet.

Super Turbo:
- 13 IDs
- 1 root ID
- next 3 IDs under the root
- next 9 IDs under those positions

Hyper Turbo:
- 22 IDs
- Do NOT invent an unsupported internal placement structure.
- Keep Hyper Turbo internal placement configurable until the exact placement logic is formally finalized.
